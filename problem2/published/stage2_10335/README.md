## 流程与完整参数

每轮从当前搜索解随机选择5/7/9工件扰动 → 所选工件A/B/机器联合插入重建（最多45秒）→ 释放全体工件做基本邻域下降与联合插入（含重建合计最多120秒）→ 判定精修条件 → 必要时依次放开A/B宽5、7、9窗口，各自最多90、120、180秒（含建模）。Gurobi6线程、强化及紧凑模型开启，复用环境，不启用候选弧约束或通用范围缓存；同一完整参考上已证明的窗口单独留存，避免重复证明。

- `always`：每轮下降后都精修。
- `gated`：仅当下降候选目标不大于本轮开始时该运行的全程最好值才精修；条件只判定一次。跳过后仍保留候选，用原有外层接受规则继续探索。

全程最好与当前搜索解分离。新全程最好优先接受；其他候选相对全程最好超过3%拒绝，不差于当前则接受，其余按`exp(-(候选-当前)/T)`接受。初温为该起点目标的0.5%，每轮乘0.98、最低1；连续6轮未刷新全程最好时回最好并重置温度，扰动组大小仍按原规则轮换。最多100000轮；余时小于180秒不再开新轮，单轮最多540秒且受总截止约束。严格最好始终保留。
