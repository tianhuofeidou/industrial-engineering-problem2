# 一阶段目录索引

[项目总索引](../../项目索引.md) · [运行说明](../README.md) · [实验记录索引](../docs/实验记录索引.md)

正式入口为`python -B -m problem2.stage1.main`：从原始输入执行8次构造与完整局部下降、模拟退火、Gurobi区间重排。运行前在项目根目录准备只读原始PDF及Excel，输出必须为不存在的新目录。

|参数|当前默认值|
|---|---|
|构造次数|8|
|退火初温倍率/降温/每层移动|2 / 0.97 / 1000|
|退火时间上限|90秒|
|区间初始宽度/每轮上限|5 / 5秒，宽度自适应|
|精确阶段时间/轮数|110秒 / 80轮，先达到者停止|
|线程数/总预算|8 / 600秒，包含初始化|
|批量初始化/范围缓存|默认开启 / 默认关闭|

600秒是上限，不自动将剩余时间分给精确阶段。`multistart_budget.py`为另行授权的多起点研究入口，不等同正式单起点。实际函数调用为`main.run → construction.initialize → annealing.run_annealing → windows.refine_windows`；区间约束和选择由`neighborhoods.py`提供，模型及验证由`common`实现。

## 可选宽度上限（2026-10-23开发，本次公开接口与基础测试）

`refine_windows(..., max_width=None)`不传时保留原策略与固定宽度研究调用；显式`max_width=7`或9可限制初始和自适应扩大的宽度，缩小规则不变。正式main参数和默认未切换。见[独立短验证](../experiments/width_cap_probe.py)、[测试](../tests/test_width_cap.py)和[本次记录](../results/width_cap_probe/run01/实验记录.md)。
