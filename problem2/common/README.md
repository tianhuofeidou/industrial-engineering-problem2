# 共用模块索引

[项目总索引](../../项目索引.md) · [运行说明](../README.md) · [实验记录索引](../docs/实验记录索引.md)

本目录统一题意规则、完整评分、一般精确模型、限制生成和验证。正式阶段与研究入口复用这些实现，不在入口复制换模或加工时间公式。

阅读顺序：`data.py → encoding.py → solver.py/solver_utils.py → validation.py → export.py`。`candidate_arcs.py`、关系追踪及稳定约束属于独立研究能力，正式默认流程不启用退火候选限制。`exact_cache.py`提供范围证明缓存，但正式入口默认关闭。

本索引列出当前工作区实际文件。标记“仅本地”的新增研究模块或测试尚未提交，不保证下载公开仓库后存在；“已跟踪”也不代表本地修改已推送。历史命令与参数只适用于对应实验，不自动成为正式默认值。
