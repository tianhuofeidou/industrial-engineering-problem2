# 一阶段两个自由工件模型的单轮时间对照

本实验只诊断受限Gurobi模型的单轮时间，并在获得改善证据后进行三个种子的总预算对照。默认一阶段代码及参数不变，不建立Case 2完整模型。

## 同模型诊断

从上一轮自由工件实验读取种子11、23、37的guided首轮，以及种子37的random第5轮。最后一个范围曾经改善，作为检查求解能否重复找到改善的对照，并非随机抽样的成功率估计。

每个范围独立冷启动求解5、15、30秒，均使用同一参考编码、相同固定关系、8线程及现有模型强化参数。各范围轮换时限顺序；逐次核对MPS的SHA-256与原模型相同。延长运行不沿用较短运行产生的新解、节点或下界。记录状态、节点、可行值、受限下界、gap、真实求解及建模耗时。

这里重用了历史参考编码，诊断时间不包括历史构造和退火成本，不可当作从原始输入得到该目标的总用时。

只有15秒或30秒相对于该范围本轮5秒产生更低可行值，或首次完成受限OPTIMAL证明，才启动后续对照。选择所有满足条件运行中最短的时限。该选择是针对这四个范围的实验规则，不表示已找出普遍最佳时限。仅增加节点数而没有上述效果则停止此方向。

## 相同总追加预算对照

从原始Excel重新为种子11、23、37各进行8次构造、完整局部下降和默认2倍初温退火。每个种子的interval、guided、random从同一新生成编码开始，各追加110秒，包含读取、选择、建模、求解、验证和导出。interval保留原5秒区间流程；其余使用诊断选出的单轮时限。总预算相同并不意味着轮数或计算工作量相同。

自由工件选择、固定约束及档案过滤与[上一轮设计](一阶段自由工件对照.md)一致，仅改变单轮时间。两个工件可在前后段分别任意插入并选择机器；其余33个工件只固定机器和相对顺序，工序时间不固定。全部固定值来自本分支当前最好可行编码，参考解必须保留。三种方法轮换执行顺序，串行运行。

## 运行与核验

```powershell
python -B -m unittest discover -s problem2/tests -t .
python -B -m problem2.experiments.stage1_round_time --output problem2/results/stage1_round_time/run01
```

输出目录必须不存在。程序保存源码快照、原始输入哈希、完整调度、每轮固定条件、MPS、日志、状态和改善编码。结束后独立验证10工位调度、模型哈希、固定条件、参考可行性及同种子相同起点。所有最优状态、下界和gap只对本轮受限范围有效，不是原题全局证明。求解器时限及总追加预算是在边界检查，实际耗时允许有少量导出开销，逐次如实报告。

本实验入口没有自动30分钟全局截止；上述固定实验预计求解约22分钟，研究总预算由本次执行时的时间检查控制。诊断无效则不会运行后续九组。

## 已完成结果

|种子|原区间5秒|信息选择15秒|随机选择15秒|
|---:|---:|---:|---:|
|11|11052|11052|11052|
|23|10873|10945|10952|
|37|10932|10962|10932|

每组均追加约110秒；对应种子公共准备为46.06、42.16、44.78秒，单条完整流程须加上该准备时间。正式实验1279.08秒，另有实现、测试及事后核验成本。

种子23的档案选择第2轮模型与上一轮5秒模型哈希相同，从10952改善到10945，并在受限范围完成证明。正式九组结束后再独立复跑5、15、30秒：5秒仍无改善，15/30秒均找到10945并完成受限证明。种子37随机方法相同10932的首次改善反而从28.20秒推迟到68.87秒，说明延长每轮会减少范围检查数量。

保持默认区间流程，不统一改成15秒。82项回归测试通过，最终验证536份完整调度、257个模型；诊断及比较均不构成全局最优证明。详见[逐次实验记录](../results/stage1_round_time/run01/实验记录.md)。补充复跑仅用于事后诊断，不反馈搜索。
