# 启发式与区间精确重排：研究方案V2

沿用前段排列a、工位6完工全序b、按工件编号存储的机器归属。目标和完整时间递推均由 `encoding.py` 提供。新研究入口为 `problem2.research_main`，原稳定关系、遗传、四算法对照入口保留。

## 1. 第一版的问题

固定关系保留参考可行解，却未必保留更好的解。Case 1退火和变邻域的三个范围均已证明最优5063，而完整模型的已知最优是5031，这已经说明固定范围排除了所有5031解。比较已有全局最优调度仅用于事后诊断，不能用其排列选择要解除的关系。

原解除规则按直接记录的条数删除25%。部分先后关系可由其他先后关系推出，删除一条记录不一定放开对应决策；删除顺序也受到工件编号和A/B字典顺序影响。全程不变只跟踪初始关系，发生一次变化即取消；退火的高温探索使Case 2所有初始关系都曾变化，因此其固定依据实际来自单次搜索的后期一致样本。

Case 2原受限模型仍有3732个0/1变量，120秒只处理根节点。变量数量不是计算复杂度的充分指标：Big-M约束的线性松弛中，未取整数的弧和先后变量仍可使大量工序重叠，求解器下界很低。

## 2. 模型强化

### 2.1 排除不可能的相邻弧

若固定先后已经推出i在k前、k在j前，则A或B上i→j不可能紧邻。固定先后也排除反向弧、不可能的首件和末件。

工位6同一条队列上的弧还必须符合B的完工先后；若夹在i与j之间的k已经固定属于该机器，则i→j不可能紧邻。k的机器归属不确定时不能据此删除弧。不能因为k在B中间就断言它也在同一机器队列中间。

每个必加工的节点有一个紧邻前驱和后继；若排除冲突后只剩一个候选，该弧必须取1。由工位6必选弧推导两端真实工件的机器归属，重新排除冲突直到不再变化。只推导逻辑上必然的决策，不能凭参考解的某条弧直接认定它必选。

### 2.2 从固定关系推导时间上下界

`time_bounds.py`将必须满足的时间条件写成 `t[v] >= t[u] + d`。节点是每道工序的开始、完成以及Cmax；边包括加工时长、工位转移、已固定的机器先后、相邻换模以及B对应的工位6完工先后。

一般先后关系只能添加不含换模的机器不重叠下界；只有确定相邻时才添加对应的换模时长。确定相邻同时增加 `S[j,k] >= C[j,k-1]+setup[i,j]`，禁止提前换模。

按拓扑顺序向前计算下界，再从可行上界H向后计算上界。未确定机器归属时，工位6加工边取较快机器的时长；归属已固定为6-2时取四舍五入后的慢机时长。所得界对当前固定范围内、目标不超过H的所有调度有效。开始时间仍是决策变量，不把下界等式化。

例如弧i→j的机器时间约束用 `M=max(0, UB(C[i,k])+setup[i,j]-LB(S[j,k]))`。若取z=0，由变量界可知约束自动满足；取z=1恢复原换模下界。B的完工排序使用完成时间的下界，避免继续使用较松的加工时间累加界。

模型强化仅在新研究入口显式开启，旧入口默认行为保留。强制弧和时间界的推导统计写入每轮 `proof.strengthening`。

## 3. 多次搜索的记录

研究入口可按多个独立种子分别初始化和搜索，保存各自最好解、最近不同接受解及记录。最终参考方案取实际评价过的最好完整编码。质量阈值内的不同样本参与关系交集，至少两次搜索有样本支持才标记 `independent_runs`。

交集仍不是全局有效约束。支持次数和不同种子数必须报告，新增搜索的时间不能省略。不同编码也可能只差很少，不应把样本数当作统计独立样本数或最优性概率。

关系在样本中不一致的比例只用于选择重排位置，不改变解码、目标或退火接受规则。研究入口可以单独求这个交集范围，作为筛选质量诊断。

## 4. 区间重排

每轮在A、B各选择一个连续区间，区间长度默认5。固定区间外所有工件的位置：具体用参考排列中的先后关系约束每个区间外工件与其余工件。区间内工件可以重排。属于任一区间的工件允许重新选择工位6机器，其余机器归属固定。

这种范围比“只保持未选工件的相对顺序、允许选中工件插入任意位置”更小。限制来自本轮邻域设计，不是原题约束；通过不断更换区间，后续轮次允许其他位置变化。工位6时间仍由一般模型求解，B必须对应实际完工先后，不能把B当作独立于工位6时间的后段序列。

选择顺序在以下三种方式之间轮换：

1. 从最终完工工序反向检查取等号的时间递推，优先包含较多影响最终完成时间的工件。
2. 优先包含不同搜索样本中机器或先后关系分歧较多的工件。
3. 使用固定随机种子选择未尝试区间，扩大覆盖。

处理多个依赖同时取等号时保留它们，所得权重仅用于选择，不宣称是唯一关键路径，也不将各权重之和解释为Cmax。

参考编码、区间宽度和两区间起点相同时不重复求解。连续6轮未改善且最近3轮求到OPTIMAL时扩大区间，最多9件；Case 1上限6件，避免自动转为完整模型。超时且无改善时缩小区间，下一轮仍更换位置。每轮默认最多5秒，总精确阶段默认最多120秒、36轮，先到者结束。

求解时间上限受求解器检查频率影响；建模、验证和导出也耗时，所以实际阶段用时可能略超过上限，必须报告实际用时。参考解始终可行，保存每轮上下界和完整调度；无改善保持原最好值。并非把一轮受限OPTIMAL当作所有区间或原题最优证明。

这是大邻域搜索：每轮固定部分决策，用商业求解器优化剩余决策。相关研究见 [通用大邻域搜索框架](https://arxiv.org/abs/2004.00422)。模型界与Big-M处理参考 [Gurobi模型强化说明](https://support.gurobi.com/hc/en-us/articles/13793044538001-General-guidelines-to-strengthen-a-MIP-formulation)。本题约束及具体筛选规则由本项目实现，不直接套用文献的实验结论。

## 5. 入口与证据

从项目根目录运行：

```powershell
python -B -m unittest problem2.tests_stable problem2.tests_research problem2.tests_four_methods problem2.tests_genetic problem2.tests_exact_case1
python -B -m problem2.tests_research --integration
python -B -m problem2.research_main --case 1 --seeds 11 23 37 --variants stable window --solver-seconds 45 --output problem2/results/research_v2/case1_new
python -B -m problem2.research_main --case 2 --seeds 11 --variants window --solver-seconds 120 --output problem2/results/research_v2/case2_new
```

`--reference`可以读取同算例的已有完整调度，跳过初始化与搜索；结合 `--evidence`可诊断原稳定关系。`--variants full`是显式的完整模型性能诊断，不是默认流程；它也获得同一参考初始解，用来隔离“缩小范围”产生的影响。完整模型和受限模型的证明范围分别记录。

`--sa-comparison`在区间阶段后另做重复退火对照。两者共享相同的初始化和第一次搜索结果；对照方只从自己的最好解继续，不读取区间阶段的改善解。每次完成完整降温流程，直到追加实际用时达到区间阶段实际用时，因此最后一次可能使对照方获得更多时间。比较完整目标和两者实际阶段用时；这比只把额外精确时间与一次退火比较更有意义，但仍不称严格相同时间预算。

每次输出包含输入和代码哈希、准确源码快照、各种子结果与样本、选中关系、参考调度、每轮模型/MIP start/日志/完整调度及检查点。不同方法比较时单独报告共享准备成本和实际精确阶段时间，已有调度诊断不能作为整条流程的耗时。

35项单元测试覆盖旧算法兼容及新范围。新增6种模型与3工件全体288个编码穷举对照：无固定、A先后固定、B先后及归属固定、相邻固定、全部固定、不同A/B区间。检查加强后的弧和时间界保留所有应保留且不超过参考上界的调度。正式试跑结果另写实验记录。
