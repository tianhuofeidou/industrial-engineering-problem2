# 追加退火、区间求解与记录筛选约束对照

目标是核验退火之后的预算应如何使用。仅处理题目2 Case 2，不调用完整大模型，不以10890或10847作为搜索停止目标。

## 共同准备与比较范围

种子11、23、37均使用8次贪心构造与完整下降，再完成2倍初温、降温0.97、每层1000次、终温为标定温度1e-4的退火。前置退火完整运行，避免记录开销造成不同迭代截断。每条轨迹额外运行一次未记录退火作诊断；最佳编码、目标、接受次数和终止信息须与记录版一致。额外诊断不计入算法成本，但计入整场实验墙钟时间。

同种子的ABC从同一编码出发。C需要其他种子的记录，因此三条准备为公共批次：报告逐分支追加时间，也报告各方法三个分支加全部公共准备的组级时间，不把单条准备加C分支冒充独立部署的全部成本。顺序运行，种子11为ABC、23为BCA、37为CAB，减少固定方法顺序的影响；不并发竞争CPU，不用平均值评价。

## 方法与预算

- A：每轮从本路线最好编码重新校准退火，种子为原种子加100003乘轮号。保留历史最好者，可完成多轮或在最后一轮截止，不接收B/C结果。
- B：沿用当前区间规则，宽度初始5，最多80轮、每轮5秒、8线程、强化和精简开启、环境共用、范围缓存关闭。
- C：筛选记录固定关系，最多3轮、每轮最多40秒、8线程、同样开启强化和精简。当前范围OPTIMAL无改善时解除25%最弱直接关系，TIME_LIMIT无改善停止，不为用完时间扩大到完整模型。

分支追加预算110秒，计入读取、C筛选、建模、求解与导出。时间在检查点停止，报告真实耗时和提前停止原因，不能称三个分支实际耗时严格相同。

## 持续记录与筛选

记录机器归属和A/B两两先后，不记录固定相邻。用本次已抽取的操作更新实际改变的关系：插入最多n-1对，交换最多2n-3对，机器翻转一条。首次改变后仍持续统计两种方向的试探、接受、高温次数和完整候选分差；完整候选分差不是单条关系的独立影响。观察器不调用随机数，不增加候选评价。

保存接受的不同优质编码与每次新最好编码，优质为本次最好值1.01倍以内，最终按最终最好值再筛选。重复编码不增加支持次数，最多保留1024个低分不同编码；样本不是独立同分布数据，支持比例不解释为置信概率。

种子至少有5个不同优质编码才能参与筛选，至少2个有效种子；对参考编码中每条机器或先后关系，各有效种子支持比例都至少95%，改变参考取值的试探总数至少20。同等或更好的已知编码具有相反取值时不固定。所有固定值从同一参考编码取，保留参考可行性。阈值是本轮待验证设置，不宣称已经最佳。

C每轮重新推导传递关系和相邻弧排除，静态计数与实际模型NumBinVars核对；解除直接关系后不得保存旧推论。无支持关系或未减少选择变量时记录筛选失败并跳过，不用区间固定补齐数量。

## 已完成实验

本轮种子11的A最优（10955），种子23和37的B最优（10873、10932）；C均无改善。C固定435、444、441条关系，仍有4538、4262、4334个0/1变量，首轮超时后提前停止。事后检查发现C排除了A/B部分已验证改善编码，说明当前样本共识直接转为固定约束存在明显局限。

记录前后退火结果一致；78项回归测试、3个小实例穷举核验、416份完整调度和197个模型核查通过。完整逐次目标、时间、记录开销及范围诊断见[实验记录](../results/abc_comparison/run01/实验记录.md)。本轮不修改一阶段默认流程，不宣称已经找到全局最优。
