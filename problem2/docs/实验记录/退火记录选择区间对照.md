# 退火记录选择区间对照

## 要回答的问题

退火给区间模型提供最好编码，但当前正式入口没有使用轨迹选择区间。已有关系分歧评分按端点工件加权，可能只开放一个端点，实际关系仍被固定。研究两种评分，仅对本轮可以改变的关系计分；不新增由统计关系推断的固定约束。

## 三种方法

1. baseline保留现有关键工序、空分歧随机同分、随机选择的三轮循环。
2. disagreement仅替换三轮中间那一轮，用优质完整编码与当前参考编码的关系分歧评分。
3. trials仅替换中间那一轮，用优质解附近试探中目标变化不超过50的出现比例评分。

三者均使用宽度5、每轮最多5秒、8线程、最多5000轮、关闭宽度调整及范围缓存。固定关系、模型强化、解码和严格改善接受规则共用已有实现。不同区间可能包含不同工件并集，因此具体变量数可能不同，不宣称各模型变量数完全相同。

## 记录、评分与范围

使用原退火操作回调，不抽取额外随机数、不评价额外候选。继承持续关系记录，质量范围为最好目标的1.03倍，最多512个不同优质编码。新记录同时统计当前状态在最好目标1.03倍以内的试探，区分改变前的0/1关系方向以及完整候选目标差值是否不超过50。这个差值来自整个移动，不能解释成单条关系的独立影响，也不把比例当作改善概率。

分歧法只使用目标不超过当前参考值1.03倍的完整样本；参考改善后重新计算所有方向。试探法只给至少有5次近优尝试的当前方向计分。分歧或尝试不足时同分随机选择，不自动增加固定关系。

选A、B区间时，顺序关系仅在两端都进入相应区间时计分；机器关系仅在工件进入两段并集时计分，同一工件不重复计算。当前参考解的区间外固定关系仍从同一个编码提取，保证参考可行。

## 预算与对照

三个种子23、53、71重新从原始Excel构造并完整下降，然后分别完成一次普通退火和一次带记录退火，两者最好编码、终止参数和接受次数必须一致。普通退火用于测量基线成本；带记录退火用于生成反馈。该额外诊断的实际耗时计入实验墙钟，不重复计入单条算法成本。

同种子三种方法共享同一退火最好编码。每条完整方案从初始化完成后计210秒：基线扣除普通退火实际耗时，两种反馈法扣除带记录退火实际耗时，再将剩余预算给加载、选择、求解、验证和导出。这样记录和评分开销不会获得免费计算时间。初始化单独记录并加入独立算法成本。三方法串行、顺序轮换，不共享Gurobi新解。

用户研究总预算45分钟，驱动器使用绝对UTC截止时间，不在剩余时间不足时新开整组，结束时如有未运行组明确报告。
