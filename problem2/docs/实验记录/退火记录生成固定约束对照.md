# 退火记录生成固定约束对照

## 研究范围

本轮研究固定约束的生成，不更换求解起点。三个种子23、53、71各自从原始Excel完成8次构造、完整局部下降和完整退火。每个种子的所有对照模型均使用同一个退火最好编码作为初始解和固定值来源。

## 记录的含义

观察器统计前段、后段相邻关系，以及机器归属和两两先后关系的改变尝试。只统计移动前的目标值不超过当时最好值1.03倍的试探。每次试探记录完整候选的目标值；这个值不解释为单条关系造成的损失。被拒绝的候选也计入试探证据，已接受的优质编码和新最好编码保存为样本。

前段样本按不同前段排列去重；后段样本按不同后段排列去重；机器样本按不同机器数组去重。同一排列或机器数组保留目标值最小的样本。原始观察器还分别按前段和“后段＋机器数组”保存最多4096组，避免许多前段变体重复支持相同后段。

候选固定关系须至少有5个不同样本、95%一致率及20次改变尝试。若已有同等或更好的样本或试探候选打破它，不将它作为新增固定关系。这个规则是启发式选择规则，不能证明关系在原题最优解中成立。观察器不调用随机数、不额外评价候选；完整无记录退火与记录退火逐温度层核对接受数、当前目标值、最好编码和终止信息。

## 约束生成

先统计仅使用上述证据能生成多少固定关系和剩余二进制变量，不自动求解未充分缩小的Case 2完整模型。

实际模型从原宽度5区间的附加限制出发。解除一个工件在前段或后段中的全部直接先后限制，使其能插入其他位置；不复制旧传递闭包，交给共享模块重新计算推论。记录方案优先选择样本分歧多、近优试探中完整目标变化不大的工件。

随后补充记录支持的前段、后段相邻关系，以控制模型规模。解除工件所在段的相邻弧若涉及该工件，不重新固定。保留机器归属的原区间规则，不再依据95%一致率额外固定机器。所有相邻弧及其他固定值都来自同一个参考解。

随机控制组使用相同的解除和补充操作形式，但随机选择工件和参考解上的相邻弧。候选相邻弧仍至少有20次改变尝试，不要求一致率或排除同等目标值反例。随机控制用于判断记录的筛选是否比随机选择更有用，不把其固定值称为题目规则。

两种生成方式最多尝试8个工件，逐条补充相邻弧，保留二进制变量数量最接近原区间模型的结果；相差不超过20%则标记为规模接近。达不到时如实报告，不宣称严格相同规模。由于传递关系和相邻弧排除具有离散变化，变量数不保证完全相同。

必须区分两类来源：原区间限制继续属于人为缩小范围；新增相邻限制由记录或随机选择提供。不能把全部固定条件都称为有记录支持。

## 求解对照

每个种子预先选择6组区间，三种方法为原区间、记录生成、随机生成。区间沿用原关键工序、随机同分和随机规则，不读取历史求解结果挑区间。三个方法串行、循环变换先后顺序。

每个初始模型Gurobi最多10秒，8线程，使用同一个参考编码和同一个目标上界，启用已有强化及紧凑模型。所有模型检查当前参考解可行。

若生成模型已达到受限最优而且没有改善，可解除四分之一较弱的新增相邻关系，重新计算推论，使用本组20秒总预算的剩余时间。解除后的模型若超过解除前二进制变量数的两倍则不运行。超时无改善不触发解除。原区间组没有新增相邻关系，不重复求解已经证明无改善的相同模型。

初始模型结果与解除后结果分别记录。主要比较初始模型；解除后的结果用于检查限制是否过强。统计记录、约束生成耗时另外报告，本轮属于固定范围诊断，不宣称完整算法端到端同预算比较。
