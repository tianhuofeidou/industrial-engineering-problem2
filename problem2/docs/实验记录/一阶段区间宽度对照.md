# 一阶段区间宽度对照

## 要回答的问题

当前区间精确阶段从宽度5开始，超时无改善时缩小，连续无改善且最近范围已证明最优时扩大。本实验比较固定宽度3、5、7、9，以及保留该自动调整规则的方案，不修改正式默认参数。

## 同起点对照

Case 2使用种子23、53、71。每个种子从原始Excel重新进行8次贪心构造、完整局部下降及完整退火，取该次退火最好编码。五组共享该编码，不共享其他组得到的解、上界或限制。此前的计算结果不参与初始化。

每组追加180秒，Gurobi每轮最多5秒、8线程，共用环境但各轮重新建立模型，启用现有模型强化和紧凑约束，关闭范围缓存，轮数上限5000以避免80轮截断。初始化时间单独记录，并加入各方案独立运行的完整成本。不同宽度允许的重排范围不同，不强求同一对区间；保持同一个选择函数、种子及接受规则。运行顺序按种子轮换。

前段、后段各开放一段连续工件，区间内可重排，其余前后关系固定；区间工件并集可换机器，其他工件的机器固定。工序时间不固定，工位6允许继续等待，完工顺序仍须与后段排列一致。只接受严格改善。

总预算包含加载、选择区间、建模、求解、验证和导出；阶段或候选之间检查截止时间，结束导出及求解器停止可能有小幅超时，报告实际用时。全部结果仅为受限范围求解，不构成原题全局最优证明。

## 宽度3的穷举对照

每个种子从同一退火编码取3个区间组合，分别使用关键工序、变化记录和随机选择规则。正式一阶段没有变化记录，所以变化记录规则在此以随机打破同分选择。各范围独立从原参考编码开始。

完整遍历两段排列以及区间工件并集的机器分配。候选数为`(w!)^2 * 2^u`，其中u是两个区间中不同工件的数量。全部候选含35个工件并计算完整10工位。对同一范围运行Gurobi，最多30秒，比较受限目标值与总耗时；只有Gurobi证明受限最优时才要求两者目标一致，超时则分别报告。

穷举使用现有批量评分器，固定一批后段及机器数组，重复评价不同前段排列时复用计算；不会把所有候选逐个生成完整工序表。穷举计时包含限制生成、数组准备和评分，Gurobi总耗时包含建模、求解、验证和文件导出；这一计时差异在结果中明示。

## 文件与验证

- `stage1/windows.py`仅增加`adaptive_width=True`选项；默认原有行为不变，False时不扩大或缩小。
- `experiments/stage1_width_comparison.py`组织实验、保存源码和输入哈希、完整调度、逐轮限制及模型。
- `tests/test_width_comparison.py`核对固定宽度、范围耗尽、重叠区间和完整穷举数量。
- 独立验证全部保存调度、固定关系、模型哈希以及同种子的起点一致性。

运行：

```text
python -B -m problem2.experiments.stage1_width_comparison --output problem2/results/stage1_width_comparison/run_new
python -B -m unittest discover -s problem2/tests -t .
```

逐次报告最终目标、最好目标首次出现时间、真实用时、轮数、改善次数、OPTIMAL轮数，不用平均数代替各次结果。实验记录保存在输出目录，不预先改变正式方案。

## 已完成的对照

正常用户许可证运行的结果位于`problem2/results/stage1_width_comparison/run02/`。`run01`为沙箱账户与许可证用户名不匹配的失败启动，不参与比较。正常实验实际用时2866.288秒，约47分46秒，另有实现和整理时间。

种子23的自动调整最好值首次在追加173.570秒保存；种子53固定5首次在24.980秒保存11026；种子71固定5首次在136.934秒保存10917。三次初始化加退火成本分别41.537、40.157、42.398秒。各组真实追加用时180.039～180.105秒，均按时间预算停止，没有达到轮数上限。

固定3的三次运行分别检查726、797、725轮，各范围全部OPTIMAL，但最终值均不及本种子的最好组；固定5分别170/171、163/164、153/155轮OPTIMAL；固定7为9/37、11/40、13/45，固定9为1/35、0/34、1/35。固定5在两次对照中较好，自动调整在另一次较好，不支持直接认定一个规则普遍更优。

同种子固定5与自动调整的开头分别有10、6、8个模型完全相同，随后范围和搜索路径不同；不能把后续不同结果归因于某一单独范围的宽度。完整数据见`逐次结果.csv`、`逐轮记录.csv`、`post_audit.json`和`实验记录.md`。

九个宽度3范围穷举和Gurobi均得到相同受限最优值，候选数1152或2304，穷举准备加评分0.0315～0.0395秒，Gurobi含建模和导出0.1109～0.1460秒。九个范围的最优值均与各自参考解相同；这说明这些范围不能严格改善，不说明其他宽度3范围不能改善。Gurobi单范围对照分别新建环境，而正式阶段共用环境，且穷举计时不含导出；耗时差异不能全部归因于算法。尚未验证把穷举替换进完整180秒流程的结果。

独立核验6643份完整调度、3299个模型、源码和原始输入哈希、固定关系及五组起点一致性，94项单元测试通过。现有Python文件仅`stage1/windows.py`发生预期修改，正式默认参数不变；实验入口、测试和文档独立新增。
