# 一阶段两个自由工件的全位置重排

在30分钟研究预算内，比较当前连续区间、按关键工序及退火档案选两个工件、随机选两个工件。原一阶段和二阶段默认流程不改，实验复用已有共享精确模型和二阶段的自由工件约束函数。

## 起点与预算

种子11、23、37重新从原始Excel进行8次构造、完整局部下降、默认2倍初温退火，完成32.6万移动。退火直接返回已有档案，不增加持续关系统计。保留档案中不超过最好值1.01倍的不同编码，最多12个；不是全体接受状态，也不解释为独立统计样本。

同种子三方法的起点相同，各追加预算110秒，含文件读取、选择、建模、求解、验证导出。每轮Gurobi上限5秒、最多80轮、8线程。按种子轮换方法执行顺序，不并发竞争CPU。全局截止检查优先于新增分支，剩余不足时保存部分记录，不冒称完成全部实验。

## 选择与固定

- interval：保留当前连续区间入口及其宽度调整，范围缓存关闭。
- guided：轮换关键工序评分、档案分歧评分、两者按各自最大值归一后相加。关键和分歧各取前10个工件，混合各取前6个，在其两工件组合中优先选分数高的未尝试范围。同分用固定种子随机打破；候选池耗尽后从其他未尝试工件对随机选。
- random：从未尝试的两工件组合中均匀抽取，不使用关键工序或档案评分。

档案分歧复用common/restrictions.py：工件参与的前后段两两顺序差异计数，机器差异按n-1计入；只是用于排序的评分，不解释为概率或独立代价。参考编码改善后重新计算评分，档案仍是本条前置退火的档案，不读取其他方法找到的结果。

guided与random均只放开两个工件：允许它们在A/B分别任意插入、分别选择机器；未选工件固定机器和相互先后，但不固定位置或工序时间。保留参考方案，静态变量计数须与实际模型一致。35工件本模型预计约663个0/1变量；该规模不能直接证明求解容易，须看实际日志和改善时间。

## 验证与运行

```powershell
python -B -m unittest problem2.tests.test_stage1_free_jobs
python -B -m problem2.tests.test_stage1_free_jobs --integration
python -B -m problem2.experiments.stage1_free_jobs --output problem2/results/stage1_free_jobs/run01
```

测试验证选中工件可以跨过区间边界、未选工件的固定条件确实有效、随机控制不使用信息评分、小实例全编码穷举与受限模型一致。正式结果逐次报告目标、时间、轮数、求解状态和档案大小；核验调度、约束及模型/源码/原始输入哈希，不报告全局最优性。
