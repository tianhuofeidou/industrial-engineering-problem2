# 后段与机器分组多参考解对照

## 要验证的问题

上一轮退火记录中，种子23产生过116种不同后段排列，但旧样本截取只留下3种。原因是按目标值、前段排列、后段排列、机器数组排序后截取前512项，同目标值的前段变体占据大量名额。这里验证保存其他后段是否能帮助后续区间精确重排。

## 样本与参考解

实验观察器按 `(后段排列, 按工件编号的机器数组)` 分组，每组只保存目标值最小的完整三数组编码。只记录已接受编码及新最好编码，候选的目标值来自原退火评分器，不额外评价、不调用随机数。最终保留目标值不超过退火最好值1.03倍的组，最多4096组。

每个种子重新从原始Excel完成8次构造及局部下降；退火使用原降温与接受规则，完整运行两次以核对记录是否改变轨迹。一组不带记录，另一组使用新的观察器。核对最好编码、全部温度层的接受数、当前目标值及终止信息。

三个参考解中，第一个是退火最好解。另两个必须有不同后段排列，且目标值最多比最好值大50。首先按目标值选取；目标值相同则优先选与已选参考解差异较大的编码。差异为后段工件对的逆序数加上机器数组不同的工件数。该选择没有读取历史最优解。

## 同预算对照

种子23、53、71各做两组，串行运行，交替组别顺序：

* single：仅从退火最好解继续精确重排。
* three：从三个参考解各自继续精确重排，剩余精确时间等分给各参考解，保留最终最好的完整调度。

每组的退火加精确阶段预算为210秒。single扣除无记录退火实测耗时，three扣除带记录退火实测耗时，再把剩余时间交给精确阶段。初始化单独计时；样本最终排序、参考解选取及准备阶段的文件导出未计入210秒，报告不将其称作完整端到端耗时。两次退火的轨迹核对属于实验诊断开销，不重复计入单一方案的耗时。

精确阶段固定区间宽度5、单模型最多5秒、8线程，使用已有区间选择规则、模型强化及紧凑模型，不启用自适应宽度、不启用结果缓存。每个参考解的固定顺序和机器归属均从该参考解独立生成，不把不同参考解的固定关系拼接。每个参考解内部接受严格改善并继续，三个参考解之间不共享求解得到的新编码。
