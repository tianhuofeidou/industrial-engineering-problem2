## 阅读代码的顺序

1. `common/data.py`与`common/encoding.py`：输入、三个数组、完整时间递推。
2. `stage1/construction.py`与`common/local_search.py`：构造随机性和初始化下降。
3. `stage1/annealing.py`：候选移动、接受规则与最好解。
4. `stage1/windows.py`：本轮区间选择及固定条件。
5. `common/solver.py`、`common/solver_utils.py`：受限模型、初始解、时间约束及证据导出。
6. `common/validation.py`：独立调度复核。
7. `stage2/joint_search.py`与`stage2/main.py`：联合重排及可选扰动。

让AI辅助阅读时，可要求它按上述调用顺序回答：“编码如何决定工位6等待？哪些关系由题目规定，哪些只是本轮固定？受限OPTIMAL能证明什么？”并逐项引用具体函数及约束。这样更容易发现说明与实现是否一致。
