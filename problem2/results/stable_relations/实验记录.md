# 稳定关系与受限Gurobi初版实验记录

日期：2026-10-10。实现已经完成，搜索记录能够直接减少Gurobi中的0/1变量；本轮精确阶段没有改善启发式最好值，尚未证明整体流程比纯启发式或完整求解器更快。

## 实验范围与参数

沿用三数组编码及完整10工位解码，目标为最终完成时间。先用8次贪心构造和完整局部下降得到共同初始解，再分别运行模拟退火、禁忌搜索、变邻域搜索。记录机器归属、两工件先后关系和队列相邻弧；从记录中选出的关系必须与最好解一致。固定决策代入常量，冲突相邻弧不建立变量，全部工序时间和工位6实际完工排序约束保留。

本次不使用遗传，不遍历工件组合。Case 1运行三种方法，Case 2只运行模拟退火；没有运行完整Case 2求解器作性能对照。设计及证据阈值见 [设计文档](../../docs/稳定关系与受限求解V1.md)。

- 随机种子11；退火最多180个温度、每温度1000次移动，禁忌连续5000步无改善结束，变邻域按既有扰动层级和连续失败规则结束。
- 全程关系的有效打破试探至少20次，退火其中至少5次在温度不低于初温10%时发生。变邻域至少10次扰动打破、局部下降恢复比例至少80%。
- 最近最多64个不同编码中，取目标不超过最好值1.03倍的最近最多24个；至少5个不同编码才能提取后期一致关系。最好解参与交集。
- Gurobi 13.0.2，8线程；最多3轮，Case 1每轮30秒，Case 2每轮120秒。范围求完且无改善时解除25%的直接关系；超时且无改善时停止。
- `--measure-overhead`先运行同参数的未记录版本作诊断。下表总耗时不包含这次额外运行，也不包含文件读取等入口开销，是初始化、记录搜索、精确阶段三者之和。

最终代码对应 `case1_run03`、`case2_run03`。早期记录实现和两次开销优化分别保留在run01、run02、run03；每次独立目录，不覆盖旧结果。代码、输入和模型哈希见各目录中的JSON。

## Case 1：三种方法

共同初始值5169秒，初始化耗时0.046秒。以下均为单次实测，不使用平均值比较，也不是等总时间预算实验。调度目标与计算用时分别列出，单位均为秒。

| 方法 | 启发式最好值 | 精确后最好值 | 未记录搜索用时 | 记录搜索用时 | 精确阶段用时 | 流程用时 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 模拟退火 | 5063 | 5063 | 1.918 | 2.533 | 0.367 | 2.946 |
| 禁忌搜索 | 5031 | 5031 | 24.336 | 28.941 | 30.123 | 59.110 |
| 变邻域搜索 | 5063 | 5063 | 2.431 | 4.768 | 0.392 | 5.206 |

| 方法 | 全程不变的关系数 | 第一轮选中关系及依据 | 每轮直接关系数 | 每轮0/1变量数（原模型282） | 精确阶段状态 |
| --- | ---: | --- | --- | --- | --- |
| 模拟退火 | 0 | 41条，均为后期一致 | 41 → 30 → 22 | 171 → 197 → 212 | 三轮均OPTIMAL，范围最优5063 |
| 禁忌搜索 | 1 | 1条，有全程及有效试探证据 | 1 | 280 | 30秒TIME_LIMIT，停止 |
| 变邻域搜索 | 45 | 35条：全程证据1条、后期一致34条 | 35 → 26 → 19 | 173 → 179 → 191 | 三轮均OPTIMAL，范围最优5063 |

变邻域的全程不变只指外层实际接受的解；仍须通过扰动和恢复证据才能选中，不能把45条都固定。退火和变邻域的后期不同样本分别为22、6个；禁忌没有足够的后期质量样本。

此前完整精确模型已证明Case 1全局最优5031秒，本次搜索没有读取该值作决策。禁忌本轮搜索达到该基准；其受限模型仍未在30秒内证明最优，下界4056.168、gap约19.38%。

退火和变邻域的三个范围都证明最优5063，说明这些固定关系排除了达到5031的解。模型容易求完并不等于固定得合适。当前规则只能保证保留作为参考的启发式最好解，不能保证保留全局最优解。

证据：[Case 1汇总](case1_run03/summary.json)、[独立核查](case1_run03/verification.json)。

## Case 2：退火与受限模型

初始化、退火和精确阶段最好值均为11086秒，完整350道工序可行。初始化28.185秒，未记录退火19.384秒，记录退火19.908秒，精确阶段121.304秒，三阶段合计169.398秒。

退火接受状态更新71856次，初始1334条关系都曾改变，没有全程不变关系。第一轮选中的671条全部来自后期24个不同较好解的一致关系：14条机器归属、650条先后关系、7条相邻弧。这些关系是启发式固定依据，不是原题必须满足的约束。

| 指标 | 本轮结果 |
| --- | ---: |
| 未固定关系时的0/1变量数（公式计算） | 6302 |
| 固定及排除冲突弧后的0/1变量数 | 3732 |
| 减少数量与比例 | 2570，40.78% |
| 缩小模型的总变量数 / 约束数 | 4503 / 32718 |
| Gurobi预处理后行 / 列 / 非零项 | 27199 / 4026 / 82841 |
| 求解器实际Runtime | 120.285秒 |
| 求解状态 | TIME_LIMIT |
| 可行目标 / 当前范围下界 | 11086 / 6272.238 |
| 当前范围gap | 43.42% |

这里的6302来自共享模型的变量计数公式 `5*n*n+5*n+2`，没有为取得该数运行完整Case 2求解器。当前范围未求完且无改善，因此只运行一轮，没有继续放宽范围。

这次确实减少了模型的可选择变量，但120秒内连当前范围的最优值也未证明。下界和gap只属于受限模型，不是原题全局下界或全局gap；11086不是已证明最优值。没有完整Case 2求解器的同机、同预算实验，不能据变量减少40.78%声称求解时间减少40.78%，也不能声称整体已经加速。

证据：[Case 2汇总](case2_run03/summary.json)、[固定关系](case2_run03/annealing/exact/round01/restrictions.json)、[求解结果](case2_run03/annealing/exact/round01/result.json)、[完整调度CSV](case2_run03/annealing/exact/final/schedule.csv)、[甘特图](case2_run03/annealing/exact/final/gantt.svg)。

## 记录开销与实现调整

初次实现对候选检查关系较慢，随后缓存关系检查结果，并用整数位表示仍需检查的初始关系；第一次实际改变后停止该关系的试探统计。不同后期样本用集合去重，所有初始关系改变后跳过试探检查。没有增加随机数调用。

| Case 2版本 | 未记录搜索用时 | 记录搜索用时 | 记录器内部计时 |
| --- | ---: | ---: | ---: |
| run01，初次实现 | 23.535 | 32.922 | 9.526 |
| run02，第一次调整 | 20.162 | 21.154 | 0.932 |
| run03，最终实现 | 19.384 | 19.908 | 0.290 |

三次选中的671条关系及证据完全相同，搜索最好编码、目标值和终止结果保持一致。各次CPU状态不同，以上单次计时不是统计意义上的速度比较。内部计时不包括所有函数调用及最终报告开销，评估记录代价应同时看完整搜索用时差。

Case 1最终版退火记录开销较小；禁忌和变邻域仍有明显开销，尤其变邻域需要检查局部下降过程。不能只观察求解器Runtime，必须同时计入初始化、搜索记录、建模及导出时间。

## 验证与交付

31项单元测试通过；6项小实例模型检查通过，包含新增的不固定、混合固定、全部固定模型和既有完整/局部模型，与288个编码的穷举结果核对。记录前后的最好编码、目标和终止结果一致。没有支持关系时跳过求解，超时无改善时停止，这两个分支也已检查。

六个试跑目录累计78份完整调度及其CSV、SVG、24个受限模型通过独立核查。检查工序完整性、加工与换模、到达和机器冲突、前后顺序、目标值、固定关系、模型哈希和范围证明标记。原始PDF、Excel及数据读取模块哈希未改变。总核查记录见 [verification.json](verification.json)。

运行命令见设计文档及项目README；输出目录已存在时拒绝覆盖。当前没有仍在运行的求解进程。旧文件备份位于 [.backups/20261010-stable-relations](../../../.backups/20261010-stable-relations/manifest.json)，其中还保存两次记录器调整前的源码，用于核对run01、run02的代码哈希。

目前得到的结论是：直接缩小模型的实现已打通，但关系筛选仍需改进。Case 1表明固定过多可能保留较差的局部范围，禁忌本次固定过少则几乎没有减少变量；Case 2表明仅靠后期一致关系仍不足以让精确阶段在120秒内完成。后续应先调整筛选与解除固定规则，再用同总时间预算、多种子实验验证最终目标和耗时。
