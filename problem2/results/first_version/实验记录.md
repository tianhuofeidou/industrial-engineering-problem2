# 题目2初版实验记录

## 方法与范围

使用自行编写的迭代贪婪算法、变邻域下降、模拟退火接受和停滞重启，不使用求解器。所有候选均计算完整10工位调度，以最终完成时间作为目标。

初版在所有工位采用最早可行时间递推。工位6按机器归属和队内顺序计算开始时间，不额外搜索主动推迟加工。因此下面是该规则下找到的可行方案，未证明原题一般模型的最优性。

- SVG结构及PNG预览已检查，灰色表示换模，彩色表示加工；短工序可通过SVG悬停详情及CSV查看。

## 使用

项目根目录运行：

```powershell
python -m pip install -r problem2/requirements.txt
python -B -m problem2.tests
python -B -m problem2.main --case all --seconds 10 --seeds 11 23 37 --output problem2/results/new_run
```

为保留本次结果，后续实验指定新的输出目录。模型说明与文件用途见 [README](../../README.md)。
