模型1730行、437列、282个二元变量。两者均为8线程、600秒求解上限，相对及绝对gap阈值0。Gurobi搜索25634个节点，COPT搜索15909个节点。COPT读取完全相同的MPS，使用Gurobi可行解作初始解，未固定任何变量；此处是最优性复核，不是相同条件的速度对照。

独立验证容差为1e-4秒；两个输出均通过70道工序核查，最终完成时间确为5031。结论：按浮点MILP求解器数值容差，本算例的全局最优完成时间为5031秒。

## 运行及首次路径问题

从项目根目录运行，复现实验使用新的目录：

```powershell
python -B -m problem2.tests_exact_case1
python -B -m problem2.tests_exact_case1 --integration
python -B -m problem2.exact_case1 --solver gurobi --seconds 600 --threads 8 --output problem2/results/exact_repeat
python -B -m problem2.exact_case1 --solver copt --seconds 600 --threads 8 --output problem2/results/exact_repeat
```

第一次启动在 `exact_case1/gurobi/` 留有5288秒初始解；Gurobi因中文绝对日志路径报错，尚未运行优化。修正为输出目录内的ASCII相对文件名后，正式成功证据放在本目录 `run01/`；首次目录不是精确结果，未拿其初始值作结论。旧结果和原始输入没有覆盖。

CSV在当前Windows环境受到透明文件加密，正常登录用户可读取；沙箱只读账户可能只读到加密头。已在正常用户环境读取CSV核查，JSON与SVG可供直接查看。
