# PPT制作交接入口

本素材包供课程项目PPT制作者使用，按**9页、10分钟**安排。重点为编码解码、算法流程与选择依据、求解效果，最后一页介绍stage2后续研究。无需阅读全部源码即可制作。

## 阅读顺序

1. [PPT制作建议](PPT制作建议.md)：每页内容、时间、图表、讲述建议。
2. [算法说明](算法说明.md)：流程、参数、公式和容易讲错的地方。
3. [实验选型依据](实验选型依据.md)：为什么采用目前方案，哪些实验支持哪些结论。
4. [结果来源](结果来源.md)：数字、调度、时间口径和原始证据。
5. [图片索引](图片/README.md)：13套SVG与PNG，含两份Case 2甘特图、Case 1甘特图及工位6详图。
6. [数据索引](数据/README.md)、[证据索引](证据/README.md)、[工具说明](工具/README.md)：可编辑表格、复核信息与生成方式。

当前正式流程是多次构造与完整局部下降、模拟退火、Gurobi区间搜索。stage2保留为可选研究方案，不能接入本次主流程图。10873不是所有预算下的一阶段最低值，较大精确阶段预算也曾得到10811，详见[结果来源](结果来源.md)中的解释。

## 文件使用

- PNG为3200×1800像素，可直接插入16:9页面。SVG保留文本和图形，便于重新排版；能否转换成原生PPT对象取决于制作者的软件。
- CSV使用UTF-8 BOM，可由Excel导入。完整调度JSON与工序表来自同一结果，不要交叉配图。
- 本文件夹可整包交给制作者。包内图片、数据、摘要可独立阅读。`../problem2/`等链接用于项目内追溯，单独复制本文件夹后这些链接不再可用。
- 数据与图表来自已有保存结果。素材制作阶段未重新运行初始化、退火或Gurobi，也未修改算法。Git提交与推送另按用户授权执行。
- 本包不是PPT成品。成员姓名、课程班级、封面格式由制作者补充。
