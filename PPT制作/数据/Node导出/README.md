## 本次核验

12份表共1285个数据行。Node表格库回读单元格与源数据一致，PowerShell独立检查文件头、SHA-256、列名及行数，并核对770道工序、56组实验字段及关键汇总。Git仅作只读文件内容哈希核对，未写入对象、暂存、提交或推送。三种程序对当前输出的字节内容一致，未出现加密文件头。

本次结果只说明这些D盘产物已通过核验，不推断本机所有目录、程序或后续导出永久保持相同行为。

## 再次生成

脚本为[导出CSV.mjs](../../工具/导出CSV.mjs)。运行需要Node、已有工作区表格库及导出记录列出的原始JSON/JSONL；部分历史归档只在本机。脚本拒绝覆盖已存在的输出目录。制作者直接使用本目录文件即可，无需重跑。
