# 素材生成工具

[交接入口](../README.md)

制作者可直接使用现有图片、JSON和说明，无需运行以下工具。脚本记录本机素材制作过程，不调用求解器或启发式搜索。当前仓库不收录12份PPT素材CSV，克隆仓库后不保证可以直接重跑全部图表制作步骤。

|文件|作用|
|---|---|
|[整理数据.py](整理数据.py)|用于本机素材制作：读取已有运行，核验三份调度并生成过程文件、JSON摘要和来源SHA；其CSV产物不上传|
|[生成图源.py](生成图源.py)|用于本机素材制作：读取本机制作数据（含未上传CSV）生成13份SVG，使用标准库|
|[导出PNG.cjs](导出PNG.cjs)|用已有sharp将SVG导出为PNG，无网络访问|

运行数据摘录需要完整项目、原始Excel与已有openpyxl环境。从项目根目录使用项目Python并加`-B`。PNG转换需要现有Node与sharp，可用环境变量`CODEX_NODE_MODULES`指定已有模块目录，不安装新依赖。已有SVG引用微软雅黑等中文字体，换环境渲染前核对中文字体。

现成图表及JSON已可直接用于PPT；此次移除不重新运行这些工具。它们会更新本素材包内自己生成的数据和图片。不要直接在输出上做唯一一份人工修改后再重跑，先另存修改版本。不会覆盖原始结果目录。
